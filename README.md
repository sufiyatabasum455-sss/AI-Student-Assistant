# AI Student Assistant

## About the Project

AI Student Assistant is a simple Python-based AI application powered by Google Gemini. It allows students to ask questions and receive AI-generated answers through an interactive command-line interface.

## Features

- Ask questions in natural language
- Receive AI-generated responses
- Simple command-line interface
- Automatic retry for temporary server errors

## Technologies Used

- Python
- Google Gemini API
- Google GenAI SDK
